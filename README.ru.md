# JePlay — CarPlay для Jaecoo

[English](README.md) · [Русский](README.ru.md)

Карты, музыка и звонки с iPhone на экране автомобиля — беспроводной CarPlay
для совместимых ГУ Jaecoo, со стрелками на HUD.

**Официальный сайт:** [https://jeplay.ru](https://jeplay.ru)

## Возможности

- **Беспроводной CarPlay** — подключение через встроенный в авто механизм, без дополнительных приборов, USB-модемов и прочего.
- **Стрелки на HUD** — манёвры навигатора из CarPlay выводятся на приборную панель, как в штатном навигаторе Jaecoo J8.
- **Карта на приборке** — масштаб под приборку (без мелкого шрифта); курсор сдвинут влево, чтобы системные подсказки не перекрывали дорогу. Масштаб и положение настраиваются.
- **Текущий трек** — название и обложка альбома из CarPlay на приборке.
- **Навигатор в подголовнике** — голосовые подсказки только в динамики подголовника водителя.
- **Обновления по воздуху** — приложение само проверяет свежие версии на сайте и скачивает обновления.
- **Установка из Chrome** — страница «Установить» подключает ГУ по WebUSB/ADB, ставит пакет, выдаёт разрешения и применяет нужные настройки.

## Совместимость

Основной фокус — **Jaecoo J8**, **Jaecoo J7**. На других моделях концерна CHERY поведение может отличаться; HUD-стрелки завязаны на конкретный сервис автомобиля.

JePlay — обычное Android-приложение: системный раздел не перепрошивается, используются штатный ADB и разрешения ОС.

## Установка

Установку **обязательно** нужно выполнять через официальную страницу в Chrome:

**[https://jeplay.ru/install.html](https://jeplay.ru/install.html)**

Не ставьте приложение простой установкой случайного APK — страница включает ADB, ставит пакет, выдаёт разрешения и применяет нужные настройки.

Нужны:

- ноутбук с **Google Chrome** (WebUSB не работает в Safari / Firefox); альтернатива — Android-телефон с OTG и Chrome;
- кабель **USB Type-A ↔ USB Type-A** (data, не только зарядка);
- USB-флешка и файл-флаг для инженерного меню / ADB;
- страница установки **https://jeplay.ru/install.html** (не `file://`).

Порт USB-C в машине часто только для зарядки — используйте USB-A, через который обычно подключают телефон для Android Auto / CarPlay.

### 1. Флешка с флагом

1. Скачайте [`svengmode.flag`](jaecoo/site/assets/svengmode.flag) и скопируйте в корень флешки.
2. Вставьте флешку в USB-разъём автомобиля.
3. Откройте инженерное меню → **USB2.0** → нижняя кнопка **DEVICE**.
4. ADB должен активироваться. Выньте флешку и подключите кабель к ноутбуку.

Если кнопки DEVICE нет — включите ADB через меню ENCRYPTION (пароль на [странице установки](https://jeplay.ru/install.html)) и переключатель ADB Switch → Open.

### 2. Пароль ENCRYPTION

На экране машины смотрите версию шифрования. В машину вводится **только пароль** из формы на сайте — не productID и не VIN. Расчёт выполняется локально в браузере.

- **Версия 1** — последние 6 или 7 цифр productID (нули сохраняйте).
- **Версия 2** — productID (полный или последние 6 цифр) и ranNum / RAND (4 цифры).

Для ENCRYPTION 3 / 3.1 на части машин сначала откройте Temperatura → Confirm (переход на версию 2), затем снова ENCRYPTION. Либо используйте флешку с флагом.

### 3. Подключение и установка

1. Кабель: USB-A автомобиля ↔ ноутбук.
2. Откройте **[https://jeplay.ru/install.html](https://jeplay.ru/install.html)**, нажмите **Connect** и выберите устройство в окне Chrome.
3. Если ГУ спросит RSA-ключ — подтвердите «Всегда разрешать».
4. Кнопка сменится на **Установить**: скачается актуальная версия (`version.txt` → `download/JePlay-<версия>.apk`), установится через ADB и выдадутся разрешения (в том числе установка обновлений из JePlay).

После установки приложение может подхватить SoftAP машины (имя сети и пароль) автоматически при первом запуске.

## Обновление

- В приложении: **Настройки → О программе → проверка обновлений** (сайт jeplay.ru).
- Или снова откройте [страницу установки](https://jeplay.ru/install.html) — она подтянет последнюю версию и поставит поверх.

Для установки через сайт интернет нужен на ноутбуке, не на ГУ. Для обновления из приложения ГУ можно подключить к интернету, либо снова использовать ноутбук.

## Подключение iPhone к CarPlay

Если телефон уже привязан к системному CarPlay:

1. Отвяжите его в настройках головного устройства.
2. Удалите из списка известных Bluetooth-устройств.
3. Создайте пару заново, но на предложение использовать CarPlay **откажитесь**.
4. Откройте JePlay, выберите телефон в списке доступных Bluetooth-устройств — приложение подключится к нему.
