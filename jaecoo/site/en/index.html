JePlay. CarPlay in your Jaecoo

Maps, music, and calls from your iPhone on the car screen — wireless CarPlay for compatible Jaecoo head units, with turn arrows on the HUD.

Install via browser

Features

One car screen — familiar CarPlay from your iPhone, plus ties into the stock Jaecoo instrument cluster.

  • Wireless CarPlay

    Connects through the car’s built-in mechanism — no extra gadgets, USB modems, or similar hardware.

  • HUD turn arrows

    Navigation manoeuvres from CarPlay appear on the instrument panel, just like the stock Jaecoo J8 navigator.

  • Map on the cluster

    The map is scaled for the cluster — no tiny type, and the cursor is shifted left so system prompts don’t cover the road. Scale and position are adjustable if you prefer.

  • Now playing

    The current CarPlay track is shown on the cluster together with album art.

  • Nav audio in the headrest

    CarPlay navigation voice prompts play only through the driver’s headrest speakers.

  • Over-the-air updates

    The app checks the site for newer builds and downloads updates itself.

  • Install from Chrome

    The Install page connects to the head unit over WebUSB/ADB, installs the package, grants permissions, and applies the required settings.

FAQ

About installing and using JePlay.

What do I need to install?

    and flag file
  • USB-A ↔ USB-A
    cable
  • Chrome on a laptop
    or Android

A laptop (or an Android phone with OTG), Chrome, a USB-A ↔ USB-A cable, and a flash drive with the flag file to enable ADB. Details are on the Install page.

Is this a head-unit firmware flash?

No. JePlay installs as a regular Android app. The car’s system partition is not reflashed — it uses stock ADB and OS permissions.

Which cars is this for?

Primary focus is Jaecoo J8 and Jaecoo J7. On other CHERY-group models behaviour may differ; HUD arrows depend on a specific vehicle service.

How do I update?

In the app: Settings → About → check for updates (jeplay.ru). Or open the install page again — it will fetch the latest build and install over the existing one.

Does the head unit need internet?

For install via the site, internet is needed on the laptop, not on the head unit.

For updates you can use the same laptop, or connect the head unit to the internet and download a fresh build.

Does JePlay work with JCarTools and DriveLabs?

If you have JCarTools or DriveLabs installed, JePlay will not conflict with them. Their settings-automation services keep working fully.

Their navigation services, however, forcibly take over the instrument-cluster output, so CarPlay navigation will only show on the head-unit screen. Or you can disable those navigator apps from JCarTools / DriveLabs and see the CarPlay map on the cluster.

How do I connect my phone to CarPlay?

If the phone is already paired with the system CarPlay, unpair it in the head-unit settings and remove it from known Bluetooth devices. Then pair again, but decline the offer to use CarPlay.

After that, open JePlay, pick the phone from the available Bluetooth devices, and the app will connect to it.

JePlay is based on the open-source DiPlay project (CarPlay client for Android head units, GPL-3.0 / AGPL-3.0 for the UI part).
