Install from Chrome

Enable ADB on the head unit, connect the laptop with a USB-A ↔ USB-A cable, press Connect — Chrome will open the device picker. After the link is up, the button becomes Install.

1. Preparation

What you need:

  • USB flash drive
    and flag file
  • USB-A ↔ USB-A
    cable
  • Chrome on a laptop
    or Android
  • A laptop with Google Chrome (WebUSB does not work in Safari / Firefox). Alternatively an Android phone with OTG and Chrome.
  • A USB Type-A ↔ USB Type-A cable (data, not charge-only).
  • A USB flash drive and the flag file for the engineering menu / ADB.
  • The page must open over https:// or http://localhost, not via file://.

The car’s USB-C port is often charge-only — use the USB-A port that normally connects a phone for Android Auto / CarPlay.

2. Flash drive with the flag

  1. Download svengmode.flag and copy it to the root of the flash drive.
  2. Plug the flash drive into the car’s USB port.
  3. Open the engineering menu → USB2.0 → bottom button DEVICE.
  4. ADB should activate. Remove the flash drive and connect the cable to the laptop.

If there is no DEVICE button — enable ADB via the ENCRYPTION menu (password form below) and ADB Switch → Open.

3. ENCRYPTION password

Read the encryption version on the car screen. Enter only the password from the form into the car — not the productID and not the VIN. Calculation runs locally in the browser.

Enter the values above

For ENCRYPTION 3 / 3.1 on some cars, first open Temperatura → Confirm (switches to version 2), then ENCRYPTION again. Or use the flash drive with the flag.

4. Connect the laptop

  1. Cable: one end in the car’s USB-A, the other in the laptop.
  2. Press Connect on the right — pick the device in the Chrome dialog.
  3. If the head unit asks for an RSA key — confirm “Always allow”.
  4. The button becomes Install: the latest build is downloaded from the site, installed over ADB, and permissions are granted (including installing updates from JePlay).

5. After installation

To keep the stock CarPlay from launching instead of JePlay:

  1. In the head-unit settings, remove your iPhone from the list of known Bluetooth devices.
  2. In Bluetooth settings, pair it again.
  3. When the head unit asks “Allow CarPlay?”, decline. This prevents stock CarPlay from starting automatically when you start the car.
  4. In JePlay, select your iPhone from the list of connected devices.
