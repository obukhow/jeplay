JePlay установка
О проекте Установить

Установка из Chrome

Включите ADB на ГУ, подключите ноутбук кабелем USB-A ↔ USB-A, нажмите Connect — Chrome откроет выбор устройства. После связи кнопка станет «Установить».

1. Подготовка

Что нужно для установки:

  • USB-флешка
    и файл-флаг
  • Кабель
    USB-A ↔ USB-A
  • Chrome на ноутбуке
    или Android
  • Ноутбук с Google Chrome (WebUSB не работает в Safari / Firefox). Альтернатива — Android-телефон с OTG и Chrome.
  • Кабель USB Type-A ↔ USB Type-A (data, не только зарядка).
  • USB-флешка и файл-флаг для инженерного меню / ADB.
  • Страница должна открываться по https:// или http://localhost, не через file://.

Порт USB-C в машине часто только для зарядки — используйте USB-A, через который обычно подключают телефон для Android Auto / CarPlay.

2. Флешка с флагом

  1. Скачайте файл svengmode.flag и скопируйте его в корень флешки.
  2. Вставьте флешку в USB-разъём автомобиля.
  3. Откройте инженерное меню → USB2.0 → нижняя кнопка DEVICE.
  4. ADB должен активироваться. Выньте флешку и подключите кабель к ноутбуку.

Если кнопки DEVICE нет — включите ADB через меню ENCRYPTION (форма пароля ниже) и переключатель ADB Switch → Open.

3. Пароль ENCRYPTION

Считайте на экране машины версию шифрования. В машину вводится только пароль из формы — не productID и не VIN. Расчёт выполняется локально в браузере.

Введите данные выше

Для ENCRYPTION 3 / 3.1 на части машин сначала откройте раздел Temperatura → Confirm (переход на версию 2), затем снова ENCRYPTION. Либо используйте флешку с флагом.

4. Подключение ноутбука

  1. Кабель: один конец в USB-A автомобиля, другой — в ноутбук.
  2. Нажмите Connect справа — выберите устройство в окне Chrome.
  3. Если ГУ спросит RSA-ключ — подтвердите «Всегда разрешать».
  4. Кнопка сменится на Установить: скачается последняя версия с сайта, установится через ADB и выдадутся разрешения (в том числе установка обновлений из JePlay).
